# 🌤️ WeatherX - Advanced Weather Application

WeatherX is a modern and responsive weather application built using **HTML, CSS, and JavaScript**. It uses the **WeatherAPI.com API** to provide real-time weather information and a 5-day forecast.

## 🚀 Live Features

- 🔍 Search weather by city
- 📍 Detect weather using current location
- 🌡️ Real-time temperature
- 🤗 Feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- 🌡️ Atmospheric pressure
- 👁️ Visibility
- 🌅 Sunrise and sunset
- 🌧️ Rain probability
- ☀️ UV Index
- 📅 5-day weather forecast
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- ⚡ Real-time API data
- ❌ User-friendly error handling
- ⏳ Loading animation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- WeatherAPI.com
- REST API
- Geolocation API
- LocalStorage
